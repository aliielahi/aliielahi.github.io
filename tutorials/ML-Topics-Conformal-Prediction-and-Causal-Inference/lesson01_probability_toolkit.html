Lesson 1: The probability toolkit behind conformal prediction

About 55 minutes. Conformal prediction and causal inference series, lesson 1 of 16. No background needed beyond "probability = fraction of the time something happens".

Why this lesson Conformal prediction lets you say things like "the true answer is inside this set 90% of the time" about any model, including a black-box LLM, without assuming anything about the model or the data distribution. The whole guarantee rests on one simple fact: if you drop a new point into a pile of similar points, it is equally likely to land anywhere in the sorted order. This lesson builds the five tools you need to state and prove that fact: the CDF, quantiles, order statistics, exchangeability and the rank lemma. Lesson 2 turns them into conformal prediction.

Running example (used in lessons 1 and 2) A risk-extraction model reads a patient note and predicts a severity score from 0 to 10. A doctor also rated each note. On 10 notes the model's error (|model score − doctor score|) was: \[ 0.3,\ 1.2,\ 0.7,\ 2.5,\ 0.1,\ 0.9,\ 1.8,\ 0.4,\ 3.1,\ 1.0 . \] A new note arrives. How large could the model's error on it be? Keep this question in mind; we answer it exactly at the end of the lesson.

1.1 Random variables and the CDF

A random variable is a number whose value is decided by chance. Example: "the model's error on the next patient note". Before the note arrives we don't know the number, but we can say how likely different values are.

Cumulative distribution function (CDF). For a random variable \(X\), the CDF is \[ F(t) \;=\; P(X \le t). \] In words: "what fraction of the time is \(X\) at most \(t\)?"

Three properties follow directly from the words:

  • \(F\) never goes down: if \(s\le t\), then "\(X\le s\)" is a special case of "\(X\le t\)", so \(F(s)\le F(t)\).
  • \(F\) goes from 0 (far left) to 1 (far right).
  • If \(X\) can take a particular value with positive probability, \(F\) jumps there, and the jump includes that value (because of the "\(\le\)").

Example. Suppose errors follow the exponential distribution with rate 1 (written Exp(1)). Then \(F(t)=1-e^{-t}\) for \(t\ge 0\). So \(P(\text{error}\le 1)=1-e^{-1}\approx 0.632\): about 63% of notes have error at most 1.

In practice we never know \(F\). We only have data. The data version is:

Empirical CDF. Given observations \(X_1,\dots,X_n\), \[ \hat F_n(t) \;=\; \frac{1}{n}\,\#\{i : X_i \le t\}, \] the fraction of observations at most \(t\). (\(\#\) means "how many".)

Example with our 10 errors. Which are \(\le 1.0\)? 0.1, 0.3, 0.4, 0.7, 0.9, 1.0. That is 6 of 10, so \(\hat F_{10}(1.0)=0.6\). Which are \(\le 2\)? Eight of them, so \(\hat F_{10}(2)=0.8\). The empirical CDF is a staircase that climbs \(1/n\) at each data point.

1.2 Quantiles

The CDF answers "given a threshold \(t\), what fraction is below it?" A quantile answers the reverse question: "given a fraction \(\tau\), what threshold has that fraction below it?"

Quantile. The \(\tau\)-quantile (for \(0<\tau\le 1\)) is the smallest threshold that has at least a fraction \(\tau\) at or below it: \[ q_\tau \;=\; \inf\{\,t : F(t) \ge \tau\,\}. \] ("\(\inf\)" means "the smallest value of", allowing for the boundary.)

Example. For Exp(1): solve \(1-e^{-t}=\tau\), giving \(q_\tau=-\ln(1-\tau)\). So \(q_{0.9}=\ln 10\approx 2.30\): 90% of errors are at most 2.30.

Empirical quantile. Use \(\hat F_n\) instead of \(F\). Sort the data. The staircase \(\hat F_n\) reaches height \(k/n\) exactly at the \(k\)-th smallest value. We need \(k/n\ge\tau\), i.e. \(k\ge n\tau\). The smallest such whole number is \(\lceil n\tau\rceil\), where \(\lceil a\rceil\) ("ceiling of \(a\)") is the smallest whole number \(\ge a\). So

\[ \hat q_\tau \;=\; \text{the } \lceil n\tau\rceil\text{-th smallest observation}. \]

Examples (sorted errors: 0.1, 0.3, 0.4, 0.7, 0.9, 1.0, 1.2, 1.8, 2.5, 3.1):

  • \(\tau=0.5\): \(\lceil 5\rceil=5\), the 5th smallest is 0.9.
  • \(\tau=0.75\): \(\lceil 7.5\rceil=8\), the 8th smallest is 1.8.
  • \(\tau=0.9\): \(\lceil 9\rceil=9\), the 9th smallest is 2.5.

1.3 Order statistics

Order statistics. Sort the observations from smallest to largest and write them as \[ X_{(1)} \le X_{(2)} \le \cdots \le X_{(n)} . \] \(X_{(k)}\) (with brackets around \(k\)) is the \(k\)-th smallest. \(X_{(1)}\) is the minimum and \(X_{(n)}\) the maximum.

Brackets matter: \(X_3\) is the third observation in the order it arrived (here 0.7), while \(X_{(3)}\) is the third smallest (here 0.4). With this notation, the empirical quantile is just \(\hat q_\tau = X_{(\lceil n\tau\rceil)}\).

Ties. If two observations are equal, the sorting is still fine but "the rank" of a value becomes ambiguous. For continuous quantities (like a real-valued error) ties have probability zero. For rounded scores (for example an LLM that outputs one of five confidence levels) ties happen; we will see that they only make our guarantees safer.

1.4 Two counting facts

Fact A: the empirical CDF is a binomial count

Fix a threshold \(t\). If the \(X_i\) are independent draws from \(F\), each one is \(\le t\) with probability \(F(t)\), like a coin that lands heads with probability \(F(t)\). The number of heads in \(n\) tosses is binomial:

\[ n\hat F_n(t)\;=\;\#\{i:X_i\le t\}\ \sim\ \mathrm{Binomial}\big(n,\,F(t)\big). \]

So \(\mathbb E[\hat F_n(t)]=F(t)\) (on average the staircase is right) and \(\mathrm{Var}[\hat F_n(t)]=F(t)(1-F(t))/n\) (its error shrinks like \(1/\sqrt n\)).

Example. If \(F(t)=0.9\) and \(n=100\), the count is Binomial(100, 0.9): mean 90, standard deviation \(\sqrt{100\cdot 0.9\cdot 0.1}=3\). So with 100 notes, the observed fraction below \(t\) is typically within about ±3 percentage points of the truth. With 10,000 notes it is within ±0.3.

Fact B: the probability integral transform

Probability integral transform (PIT). If \(X\) has a continuous CDF \(F\), then \(U=F(X)\) is uniformly distributed on \([0,1]\).

In words. \(F(X)\) is "the percentile of \(X\)". A random draw is equally likely to fall in any percentile band: 10% of draws are in the bottom 10%, 10% in the next 10%, and so on. That is exactly what "uniform" means.

Proof. For \(u\in(0,1)\), let \(q_u\) be the \(u\)-quantile, so \(F(q_u)=u\) (continuity). Then \(F(X)\le u\) happens exactly when \(X\le q_u\), so \(P(F(X)\le u)=P(X\le q_u)=F(q_u)=u\). That is the CDF of the uniform distribution. \(\square\)

Why we care. Anything that depends only on the order of the data (ranks, "which one is the 9th smallest") is unchanged if we replace each \(X_i\) by \(F(X_i)\), because \(F\) never goes down. After that replacement the data are uniform, whatever \(F\) was. So statements about ranks have the same probabilities for every distribution. This is the root of the word distribution-free.

1.5 i.i.d. and exchangeability

Most statistics assumes data are i.i.d.: independent (one draw tells you nothing about another) and identically distributed (all come from the same \(F\)). Conformal prediction needs something weaker.

Exchangeability. Random variables \(Z_1,\dots,Z_m\) are exchangeable if shuffling them does not change their joint distribution: for every reordering \(\sigma\) of \(\{1,\dots,m\}\), \[ (Z_1,\dots,Z_m)\ \overset{d}{=}\ (Z_{\sigma(1)},\dots,Z_{\sigma(m)}) . \] (\(\overset{d}{=}\) means "has the same distribution as".) In words: if someone secretly shuffled the list, you could not tell.

Example 1: i.i.d. is exchangeable. For independent draws with density \(f\), the joint density is \(f(z_1)f(z_2)\cdots f(z_m)\). Multiplication doesn't care about order, so shuffling changes nothing.

Example 2: exchangeable but not independent (drawing without replacement). An urn has 3 red and 2 blue balls. Draw two without putting them back.

first, secondprobability
red, blue\(\tfrac35\cdot\tfrac24=0.3\)
blue, red\(\tfrac25\cdot\tfrac34=0.3\)

The two orders have the same probability (and so do red-red and blue-blue with themselves), so the pair is exchangeable. But the draws are not independent: \(P(\text{2nd red}\mid\text{1st red})=2/4=0.5\), while \(P(\text{2nd red})=3/5=0.6\).

Why Example 2 matters for you Suppose you have a fixed pool of 2,000 labeled patient notes and you randomly pick which ones go to calibration and which one plays "the new note". That is drawing without replacement from an urn. So the calibration notes and the new note are exchangeable, even though nothing is i.i.d. Random splitting of a fixed pool is the most common way exchangeability is achieved in practice.

Example 3: not exchangeable.

  • Drift over time. Calibration notes are from 2019 and the new note is from 2025, after the hospital changed its documentation template. The new note's error tends to be larger. If you shuffled the list, you could tell (the big errors would move around), so it is not exchangeable.
  • Different populations. Calibration filings from banks, the new filing from a biotech firm.
  • Selection. The new note was sent to the model because a nurse found it confusing.

A rule we will use constantly. If \(Z_1,\dots,Z_m\) are exchangeable and \(s\) is a fixed function, then \(s(Z_1),\dots,s(Z_m)\) are exchangeable too: shuffling the \(Z\)'s shuffles the \(s(Z)\)'s in the same way. The word "fixed" is important. If \(s\) were built (trained) using \(Z_1,\dots,Z_{m-1}\) but not \(Z_m\), then \(Z_m\) would be treated differently and the rule breaks. This is why Lesson 2 trains the model and calibrates it on separate data.

1.6 The rank lemma

Now the main fact. Take \(n+1\) numbers \(Z_1,\dots,Z_n,Z_{n+1}\). Think of the first \(n\) as old data and \(Z_{n+1}\) as the new point. The rank of \(Z_j\) is its position in the sorted list:

\[ R_j \;=\; \#\{\,i\le n+1 : Z_i \le Z_j\,\}\qquad(\text{rank 1 = smallest}). \]
Rank lemma. If \(Z_1,\dots,Z_{n+1}\) are exchangeable and have no ties, then the rank of the new point is uniform: \[ P(R_{n+1}=k)\;=\;\frac{1}{n+1}\qquad\text{for each } k=1,2,\dots,n+1 . \]

Intuition. Write the \(n+1\) numbers on cards and shuffle. Which card is "the new one" is just a sticker. Since shuffling changes nothing, the stickered card is equally likely to be the smallest, the second smallest, ..., or the largest.

Proof, in three steps.

  1. Every card has the same chance of rank \(k\). Swap the labels of card \(j\) and card \(n+1\). By exchangeability, the joint distribution doesn't change, so the distribution of the ranks doesn't change either. Hence \(P(R_{n+1}=k)=P(R_j=k)\) for every \(j\).
  2. Exactly one card has rank \(k\). With no ties, the ranks are \(1,\dots,n+1\) in some order, so \(\sum_{j=1}^{n+1}\mathbf 1\{R_j=k\}=1\). Taking expectations, \(\sum_{j=1}^{n+1}P(R_j=k)=1\).
  3. Divide. We have \(n+1\) equal numbers adding up to 1, so each is \(1/(n+1)\). \(\square\)

Notice what we did not use: the distribution of the \(Z\)'s, independence, or anything about a model. Only exchangeability.

The corollary that powers conformal prediction

Let \(Z_{(k)}^{\text{old}}\) be the \(k\)-th smallest of the old points \(Z_1,\dots,Z_n\). The new point is at most \(Z_{(k)}^{\text{old}}\) exactly when fewer than \(k\) old points are below it, which means its rank among all \(n+1\) is at most \(k\). Therefore

\[ P\big(Z_{n+1}\le Z_{(k)}^{\text{old}}\big)\;=\;P(R_{n+1}\le k)\;=\;\sum_{j=1}^{k}\frac{1}{n+1}\;=\;\frac{k}{n+1}. \]

With ties, the left side can only be larger (a tie with the threshold still counts as "\(\le\)"), so in general \(P(Z_{n+1}\le Z_{(k)}^{\text{old}})\ge k/(n+1)\).

Back to the running example The 10 errors are the old points; the new note's error is \(Z_{11}\). Sorted: 0.1, 0.3, 0.4, 0.7, 0.9, 1.0, 1.2, 1.8, 2.5, 3.1.
  • \(P(\text{new error}\le 2.5)=P(\le Z^{\text{old}}_{(9)})=9/11\approx 0.818\).
  • \(P(\text{new error}\le 3.1)=P(\le Z^{\text{old}}_{(10)})=10/11\approx 0.909\).
To be at least 90% sure, we need \(k/11\ge 0.9\), i.e. \(k\ge 9.9\), so \(k=10\) and the threshold is 3.1.
Careful: the "obvious" empirical 0.9-quantile of the 10 errors is \(Z_{(9)}=2.5\) (section 1.2), which only gives 81.8%. The new point is the 11th card, so we divide by \(n+1=11\), not by 10. That "+1" is exactly the formula \(\lceil(1-\alpha)(n+1)\rceil\) in Lesson 2.

Summary

  • CDF \(F(t)=P(X\le t)\); the empirical CDF \(\hat F_n\) is the fraction of data \(\le t\), a binomial count with error about \(1/\sqrt n\).
  • The \(\tau\)-quantile is the smallest \(t\) with \(F(t)\ge\tau\); the empirical one is the order statistic \(X_{(\lceil n\tau\rceil)}\).
  • PIT: \(F(X)\) is uniform, so rank statements are the same for every distribution (distribution-free).
  • Exchangeable = "shuffling changes nothing". It is weaker than i.i.d. Random splitting of a fixed pool gives it; drift, different populations and selection break it. Fixed functions of exchangeable data stay exchangeable.
  • Rank lemma: the new point's rank is uniform on \(\{1,\dots,n+1\}\), so \(P(Z_{n+1}\le Z^{\text{old}}_{(k)})\ge k/(n+1)\). Lesson 2 builds conformal prediction on this single line.

Quiz

Try each one before opening the answer.

1. Data: 2, 5, 5, 7, 9, 11, 14, 20. What is \(\hat F_8(7)\)? What is \(\hat F_8(6.9)\)? Values \(\le 7\): 2, 5, 5, 7, so \(\hat F_8(7)=4/8=0.5\). Values \(\le 6.9\): 2, 5, 5, so \(3/8=0.375\). The staircase jumps at 7, and the jump includes 7.
2. Same data. What is the empirical 0.8-quantile? The 0.3-quantile? 0.8: \(\lceil 8\cdot 0.8\rceil=\lceil 6.4\rceil=7\), the 7th smallest is 14. 0.3: \(\lceil 2.4\rceil=3\), the 3rd smallest is 5.
3. You pick 5 documents at random, without replacement, from a pool of 100. Are the 5 picks exchangeable? Independent? Exchangeable: yes (it is the urn example; every order of the same 5 documents is equally likely). Independent: no; once a document is picked it cannot appear again, so the first pick changes the odds for the second.
4. Calibration notes come from January to June, and the new note from December, after a new coding standard was introduced. Why might exchangeability fail? What would you see in Figure 4? The new note's error comes from a different distribution (the model was built before the new standard), so swapping it with an old note changes the joint distribution. In Figure 4 this looks like the "shifted" case: the new point's rank piles up at the top, so thresholds taken from old data are exceeded more often than promised.
5. You have \(n=19\) old points with no ties. What is \(P(Z_{20}\le Z^{\text{old}}_{(19)})\)? And \(P(Z_{20}\le Z^{\text{old}}_{(18)})\)? \(19/20=0.95\) and \(18/20=0.90\).
6. What is the smallest \(n\) for which some old point is a threshold that the new point stays below with probability at least 0.95? The best threshold is the maximum, \(k=n\), giving \(n/(n+1)\). We need \(n/(n+1)\ge 0.95\iff n\ge 19\). With fewer than 19 points, no data-based threshold can promise 95%.
7. \(X\sim\) Exp(1). What is the distribution of \(1-e^{-X}\)? And of \(e^{-X}\)? \(1-e^{-X}=F(X)\) is uniform on \([0,1]\) by the PIT. Then \(e^{-X}=1-U\) is also uniform (flipping a uniform gives a uniform).
8. In one sentence: why does the rank lemma not depend on the distribution of the data? Its proof only uses the symmetry from exchangeability (every card is equally likely to have each rank) and the fact that exactly one card has each rank; the actual values never enter.
9. (Preview of Lesson 2.) You train a model on notes 1 to 10 and then use its errors on the same notes as the old points. Why is the rank lemma no longer valid for the error on a new note? The errors on training notes are produced by a model that has seen those notes, so they tend to be smaller than the error on a new note it hasn't seen. The new note is treated differently, so the errors are not exchangeable, and the new error tends to rank high (like the shifted case in Figure 4).
