Lesson 3: Better scores and conditional coverage

About 60 minutes. Conformal prediction and causal inference series, lesson 3 of 16. Needs Lessons 1–2.

Where this lesson goes Lesson 2 ended with a problem. The demo promised 90% and delivered 90% overall, but short notes were covered about 99% of the time and long notes only about 75%. For a patient with a long, complicated note, "90% on average" is cold comfort. This lesson answers three questions in order:
  1. Why does that happen? One equation explains it, and tells us what a good score must do.
  2. How do we fix it? Three fixes: scale the score by the difficulty (normalized scores), learn the band's shape (conformalized quantile regression, CQR), or calibrate each group separately (group-conditional conformal).
  3. How far can we go? There is a wall: exact coverage for every single input is impossible without assumptions. We prove why.
Then we do the same for classification (adaptive prediction sets).

Running example (same as Lesson 2's demo) \(x\) = note length in pages, from 0 to 10. True severity: \(y=2+0.5x+\sigma(x)\,\varepsilon\), with \(\varepsilon\sim N(0,1)\) and noise level \(\sigma(x)=0.15+0.12x\): long notes are noisier. The model is the slightly-off line \(\hat f(x)=2.3+0.46x\). Target: \(\alpha=0.1\).

3.1 The equation behind the problem

Where this section goes. We write down the coverage at one input \(x\), and find the exact condition a score must satisfy for that coverage to be \(1-\alpha\) at every \(x\).

Conditional coverage. The coverage of the prediction set at a particular input \(x\): \[ \mathrm{cov}(x) \;=\; P\big(Y\in C(X)\,\big|\,X=x\big). \] Lesson 2 guaranteed the average of \(\mathrm{cov}(x)\) over all \(x\) (marginal coverage). Here we want \(\mathrm{cov}(x)\ge 1-\alpha\) for each \(x\).

Step 1: write coverage as a score event. With a large calibration set, \(\hat q\) is essentially a fixed number. The set is \(C(x)=\{y: s(x,y)\le\hat q\}\), so

\[ \mathrm{cov}(x) = P\big(s(x,Y)\le \hat q \,\big|\, X=x\big) = F_{s\mid x}(\hat q), \]

where \(F_{s\mid x}\) is the CDF of the score among documents with input \(x\).

Step 2: what conformal chooses. Conformal picks one number \(\hat q\) so that the average of \(F_{s\mid x}(\hat q)\) over \(x\) is \(1-\alpha\).

Step 3: the condition. For \(\mathrm{cov}(x)=1-\alpha\) at every \(x\), we need \(F_{s\mid x}(\hat q)=1-\alpha\) for every \(x\). In words:

The key condition. Conformal with score \(s\) has (approximately) exact conditional coverage when the \((1-\alpha)\)-quantile of the score, among documents with input \(x\), is the same number for every \(x\): \[ q_{1-\alpha}\big(s(X,Y)\mid X=x\big) \;=\; \text{constant in } x . \]

Step 4: check the score from Lesson 2. With \(s=|y-\hat f(x)|\), and ignoring the model's small bias, \(s=\sigma(x)|\varepsilon|\). The 0.9-quantile of \(|\varepsilon|\) is 1.645, so the score's conditional quantile is \(1.645\,\sigma(x)\). That depends on \(x\): it is 0.44 at \(x=1\) and 2.02 at \(x=9\). The condition fails.

Conformal picks a single \(\hat q\approx 1.39\) for the whole population. The resulting coverage at each \(x\) (exact formula, including the model's bias):

\(x\) (pages)\(\sigma(x)\)\(\mathrm{cov}(x)\) with \(\hat q=1.39\)
10.271.00
50.750.93
91.230.74

Punchline. Conformal only chooses the level \(\hat q\). The shape of the set across inputs comes entirely from the score. A score whose spread changes with \(x\) gives coverage that changes with \(x\). So the fix is to design scores whose distribution looks the same at every \(x\).

3.2 Fix 1: normalized scores

Where this section goes. If the score's spread grows like \(\sigma(x)\), divide by it.

Normalized residual score. Train a second model \(\hat\sigma(x)\) that predicts how big the error usually is at \(x\) (for example, by regressing \(|y-\hat f(x)|\) on \(x\), using training data only). Use \[ s(x,y)=\frac{|y-\hat f(x)|}{\hat\sigma(x)} . \]

Derive the set.

\[ s(x,y)\le\hat q \iff |y-\hat f(x)|\le \hat q\,\hat\sigma(x) \iff y\in\big[\hat f(x)-\hat q\,\hat\sigma(x),\ \hat f(x)+\hat q\,\hat\sigma(x)\big]. \]

The band is now wide where \(\hat\sigma\) is large and narrow where it is small.

Validity. \(\hat f\) and \(\hat\sigma\) are both trained on the training split, so \(s\) is still a fixed function of \((x,y)\), and Lesson 2's theorem applies unchanged: marginal coverage \(\ge 1-\alpha\), whatever \(\hat\sigma\) is, even a bad one.

Check the key condition. If \(\hat\sigma=\sigma\) and \(\hat f\) were unbiased, \(s=|\varepsilon|\) at every \(x\). Its 0.9-quantile is 1.645 everywhere: constant. So conformal picks \(\hat q\approx1.645\) and every \(x\) is covered at exactly 90%. The band's width is \(2\cdot1.645\,\sigma(x)\): 0.89 at \(x=1\), 4.05 at \(x=9\).

Punchline. Normalizing moves the difficulty into the score, so one threshold works everywhere. The guarantee never depended on \(\hat\sigma\); the conditional quality does.

3.3 Tool: learning quantiles with the pinball loss

Where this section goes. Fix 2 needs a model that predicts a quantile of \(Y\) given \(x\) (for example "the value that 95% of similar patients stay below"), not the average. Ordinary regression minimizes squared error and learns the mean. We need the loss whose minimizer is a quantile, and we derive it.

Pinball loss. For a level \(\tau\in(0,1)\) and an error \(u=y-q\): \[ \rho_\tau(u)=\begin{cases}\tau\,u & u\ge 0 \ (\text{the guess } q \text{ was too low})\\ (1-\tau)\,(-u) & u<0\ (\text{the guess was too high}).\end{cases} \] For \(\tau=0.9\), guessing too low costs 0.9 per unit and guessing too high only 0.1 per unit. So the best guess sits high: only 10% of values should be above it.

Derive the minimizer. We choose \(q\) to minimize the expected loss \(L(q)=\mathbb E[\rho_\tau(Y-q)]\).

  1. Move \(q\) up by a tiny amount \(h\). Every \(Y\) above \(q\) gets its loss reduced by \(\tau h\). Every \(Y\) below \(q\) gets its loss increased by \((1-\tau)h\).
  2. So the slope is \(L'(q)=-\tau\,P(Y>q)+(1-\tau)\,P(Y<q) = -\tau(1-F(q))+(1-\tau)F(q)=F(q)-\tau\).
  3. The slope is negative while \(F(q)<\tau\) and positive once \(F(q)>\tau\). So the minimum is where \(F(q)=\tau\): the \(\tau\)-quantile. \(\square\)

A quantile regression model trains any predictor \(\hat q_\tau(x)\) (linear model, gradient boosting, a neural network on document embeddings) by minimizing the average pinball loss on training data. The minimizer estimates the conditional \(\tau\)-quantile of \(Y\) given \(x\).

Check on Lesson 1's errors. The figure plots the average pinball loss of the 10 errors as a function of the guess \(q\). Its minimum lands on the empirical quantile from Lesson 1: 1.8 at \(\tau=0.75\). At \(\tau=0.9\), where \(n\tau=9\) is a whole number, the bottom is flat between 2.5 and 3.1, and its left end is Lesson 1's 2.5.

Punchline. Changing the loss changes what a model learns. Squared error learns the mean; pinball loss learns a quantile. That lets a model learn the edges of a band, not just its center.

3.4 Fix 2: conformalized quantile regression (CQR)

Where this section goes. Quantile regression already gives a band that adapts to \(x\): from \(\hat q_{\text{lo}}(x)\) (level \(\alpha/2\)) to \(\hat q_{\text{hi}}(x)\) (level \(1-\alpha/2\)). But it has no guarantee: the quantile models may be too narrow or too wide. CQR keeps the adaptive shape and uses conformal to fix the level.

CQR (Romano, Patterson and Candès, 2019). Train \(\hat q_{\text{lo}}\) and \(\hat q_{\text{hi}}\) on the training split. Use the score \[ s(x,y)=\max\big(\hat q_{\text{lo}}(x)-y,\ \ y-\hat q_{\text{hi}}(x)\big). \]

Read the score. If \(y\) is above the band, the second term is positive: how far above. If \(y\) is below, the first term is positive: how far below. If \(y\) is inside, both are negative and the score is minus the distance to the nearest edge.

Derive the set. \(s\le\hat q\) means both terms are \(\le\hat q\):

\[ \hat q_{\text{lo}}(x)-y\le\hat q\ \text{ and }\ y-\hat q_{\text{hi}}(x)\le\hat q \iff y\in\big[\hat q_{\text{lo}}(x)-\hat q,\ \ \hat q_{\text{hi}}(x)+\hat q\big]. \]

So CQR moves both edges of the learned band out by \(\hat q\), or in if \(\hat q<0\).

Check the key condition. If the quantile models were exact, then \(P(s\le 0\mid X=x)=P(\hat q_{\text{lo}}(x)\le Y\le\hat q_{\text{hi}}(x)\mid X=x)=1-\alpha\) at every \(x\). The score's \((1-\alpha)\)-quantile is 0 for every \(x\): constant. So CQR inherits exact conditional coverage from good quantile models, and the marginal guarantee from conformal regardless.

Punchline. CQR divides the labor: quantile regression learns the shape, conformal fixes the level. In Lesson 14, Lei and Candès use exactly this score to build intervals for counterfactual outcomes.

3.5 Fix 3: group-conditional (Mondrian) conformal

Where this section goes. Sometimes you don't need coverage at every \(x\), but you do need it for groups that matter: each hospital, each specialty, short vs long notes, banks vs biotech firms. Then there is a simple method with an exact guarantee.

Group-conditional conformal. Fix a grouping \(g(x)\in\{1,\dots,G\}\) chosen without looking at the calibration labels (for example the specialty). For each group \(g\), run split conformal using only the \(n_g\) calibration points in that group: \[ \hat q_g = \text{the } \big\lceil(1-\alpha)(n_g+1)\big\rceil\text{-th smallest score in group } g,\qquad C(x)=\{y: s(x,y)\le \hat q_{g(x)}\}. \]
Theorem. If the data are i.i.d., then for every group \(g\), \[ P\big(Y_{n+1}\in C(X_{n+1})\,\big|\,g(X_{n+1})=g\big)\ \ge\ 1-\alpha . \]

Proof. Condition on which points fall in group \(g\). Those calibration points and the new point (given that it is in group \(g\)) are i.i.d. draws from the same distribution, namely documents from group \(g\). So they are exchangeable, and Lesson 2's theorem applies inside the group, with \(n_g\) in place of \(n\). \(\square\)

The cost: each group needs its own data. Suppose oncology has only \(n_g=15\) calibration notes. Then \(k=\lceil 0.9\cdot16\rceil=15\): the threshold is the group's largest score, and the coverage for this calibration set is Beta(15, 1), mean 0.94 with sd 0.06. A group with fewer than 9 points gets infinite sets at \(\alpha=0.1\). More groups means more guarantees, but less data per guarantee.

Overlapping groups (for example "oncology" and "long notes" at the same time) need more advanced methods, which give coverage on many overlapping groups at once (see the reading list).

Punchline. If you can name the groups you care about, you can have an exact guarantee for each one, paid for in calibration labels per group.

Same simulated notes as Lesson 2. 1,000 training notes fit the helper models; \(n=500\) calibrate; 5,000 test notes measure coverage (1,000 are drawn). To keep the code transparent, the helper models are simple: split \(x\) into 10 one-page bins, and in each bin use the training notes' average error (for \(\hat\sigma\)) or their empirical \(\alpha/2\) and \(1-\alpha/2\) quantiles (for CQR).

Two more things to notice. The average width in the readout: the adaptive methods are not just fairer, they are often narrower on average, because they stop wasting width on easy notes. And overall coverage stays at about \(1-\alpha\) for every method: the marginal guarantee never moved.

3.7 The wall: exact conditional coverage is impossible

Where this section goes. Could a cleverer method guarantee \(\mathrm{cov}(x)\ge 1-\alpha\) at every \(x\), for every distribution, the way Lesson 2 guarantees the average? No. We show why with a construction: a "hidden spike" that no finite calibration set can detect.

Theorem (Vovk 2012; Lei and Wasserman 2014; Foygel Barber et al. 2021), informal. Suppose \(X\) is continuous (no single value has positive probability). If a method guarantees \(\mathrm{cov}(x)\ge1-\alpha\) at every \(x\) for every distribution, then its sets have infinite expected length at (almost) every \(x\), for every distribution, including easy ones.

Proof sketch, in five steps.

  1. Start from any distribution \(P\) (say our notes). Pick an input \(x_0\) and a tiny window \(B\) around it that contains a fraction \(\delta\) of all notes.
  2. Build a second distribution \(P'\): identical to \(P\) outside \(B\), but inside \(B\) the severity has huge noise, spread over a range of size \(M\).
  3. The calibration data can't tell them apart. \(n\) calibration notes all miss \(B\) with probability \((1-\delta)^n\). When they miss it, the data from \(P\) and from \(P'\) look exactly the same. For \(\delta=0.0001\) and \(n=500\), that happens 95% of the time.
  4. The method must be safe under \(P'\). At \(x_0\), the truth under \(P'\) is spread over a range of size \(M\); to catch it with probability \(1-\alpha\), the set must be roughly \(M\) wide. Because the method sees the same data under \(P\) and \(P'\) (step 3), it outputs the same huge set under \(P\) too, most of the time.
  5. Let \(\delta\to0\) and \(M\to\infty\). The set at \(x_0\) under \(P\) must be arbitrarily wide. \(x_0\) was arbitrary. \(\square\)

So what is possible?

  • Exact guarantees for finitely many groups with enough data each (section 3.5).
  • Approximate conditional coverage from good scores (sections 3.2 and 3.4). It improves as the helper models improve, but it is not guaranteed.
  • Coverage conditional on the true label in classification (calibrate each class separately), which is just section 3.5 with \(g=y\).

Punchline. Coverage on average over all documents is free and distribution-free. Coverage for every single document is impossible without assumptions. Everything in between is bought with either data (groups) or modeling (scores).

3.8 Classification: adaptive prediction sets (APS)

Where this section goes. The same problem appears in classification. Lesson 2's score \(1-\hat p_y(x)\) gave paragraph C, the hardest one, an empty set. We build a score whose sets grow with difficulty.

Why the Lesson 2 score under-covers hard inputs. Its set is "every label with \(\hat p\ge 1-\hat q\)", a fixed probability bar. On a hard paragraph the model spreads its probability thinly, so few labels (or none) clear the bar, exactly when we would want more labels. (This score does give the smallest sets on average, so it is the right choice when average size is what matters.)

The ideal set, if the probabilities were correct. Sort labels from most to least likely and add them until their total probability reaches \(1-\alpha\). If \(\hat p\) were the true conditional probabilities, this set would contain the true label with probability at least \(1-\alpha\) for every paragraph. Easy paragraphs need one label; hard ones need many.

APS score (Romano, Sesia and Candès, 2020). Sort the labels by \(\hat p\), largest first. The score of label \(y\) is the total probability of all labels ranked up to and including \(y\): \[ s(x,y)=\sum_{y':\ \hat p_{y'}(x)\ \ge\ \hat p_y(x)} \hat p_{y'}(x). \] Set: go down the sorted list adding labels, and stop at the first label where the running total reaches \(\hat q\).

Why this set is valid. If the true label \(y\) has score \(s(x,y)\le\hat q\), the running total at \(y\) is still \(\le\hat q\), so we haven't stopped before reaching \(y\): \(y\) is in the set. So the set contains \(\{y: s(x,y)\le\hat q\}\), and Lesson 2's theorem gives coverage \(\ge 1-\alpha\). (Including the label that crosses the line only adds labels, which keeps coverage valid and prevents empty sets.)

Why calibrate at all? The model's probabilities are usually miscalibrated (LLMs are often overconfident). Calibration replaces the ideal level \(1-\alpha\) with whatever \(\hat q\) actually achieves \(1-\alpha\) on real data.

Quiz

1. In your own words: why does the score \(|y-\hat f(x)|\) give low coverage on long notes, even though overall coverage is 90%? Conformal picks one threshold \(\hat q\) for all notes. Long notes have bigger errors, so their scores exceed \(\hat q\) more often (coverage below 90%), while short notes almost never exceed it (coverage near 100%). The average is 90%. Formally, the score's conditional 0.9-quantile, \(1.645\,\sigma(x)\), is not constant in \(x\).
2. Your \(\hat\sigma(x)\) model is terrible: it predicts 1 everywhere. What coverage does the normalized score give? What if it is badly wrong, predicting large \(\hat\sigma\) on easy notes? Predicting 1 everywhere gives back the constant score: marginal coverage still \(\ge 1-\alpha\), with the same conditional problem as before. Badly wrong \(\hat\sigma\) still gives marginal coverage \(\ge1-\alpha\) (the theorem never used \(\hat\sigma\)), but conditional coverage gets worse: easy notes get wide bands and hard notes narrow ones.
3. For the pinball loss with \(\tau=0.25\), what does guessing too high cost per unit, and too low? Where does the minimizer sit? Too high (\(u<0\)): \(1-\tau=0.75\) per unit. Too low: \(\tau=0.25\) per unit. Guessing high is expensive, so the minimizer sits low, at the 0.25-quantile (25% of values below it).
4. Derive the slope of \(L(q)=\mathbb E[\rho_\tau(Y-q)]\) and use it to say where the minimum is. Raising \(q\) by \(h\) lowers the loss by \(\tau h\) for every \(Y>q\) and raises it by \((1-\tau)h\) for every \(Y<q\). So \(L'(q)=-\tau(1-F(q))+(1-\tau)F(q)=F(q)-\tau\), which is zero at \(F(q)=\tau\): the \(\tau\)-quantile.
5. CQR: a calibration note has \(\hat q_{\text{lo}}=2\), \(\hat q_{\text{hi}}=5\), \(y=5.5\). What is its score? And with \(y=3\)? \(y=5.5\): \(\max(2-5.5,\ 5.5-5)=\max(-3.5, 0.5)=0.5\) (half a point above the band). \(y=3\): \(\max(-1,-2)=-1\) (inside, 1 point from the nearest edge, the lower one).
6. CQR gave \(\hat q=-0.3\). What does that tell you about the quantile models, and what happens to the band? The learned band covered more often than needed at this \(\alpha\) (it was too wide). The final band is the learned one shrunk by 0.3 on each side.
7. You calibrate per hospital. Hospital A has 400 calibration notes, hospital B has 12. What do you expect for each at \(\alpha=0.1\)? A: \(k=\lceil0.9\cdot401\rceil=361\); a stable threshold, with coverage for this calibration set around 0.90 ± 0.015. B: \(k=\lceil0.9\cdot13\rceil=12\), the largest of its 12 scores; valid, but the coverage for this calibration set is Beta(12, 1), mean 0.92 with sd about 0.07, so it is very noisy, and B's intervals are usually wide.
8. Explain the hidden-spike argument in three sentences. A tiny window of inputs can be so rare that a finite calibration set almost surely contains no point from it. A distribution with huge noise only inside that window therefore produces the same data as one without, so the method can't tell them apart. To be safe at every input under both, the method must output huge sets at that input even under the harmless distribution, and the window can be anywhere.
9. APS with \(\hat q=0.9\): what are the sets for A (0.70, 0.20, 0.05, 0.03, 0.02) and C (0.24, 0.22, 0.20, 0.18, 0.16)? A: running totals 0.70, 0.90; the total reaches 0.9 at Liquidity: {Credit, Liquidity}. C: totals 0.24, 0.46, 0.66, 0.84, 1.00; the total reaches 0.9 only at the 5th label: all five labels.
10. For your risk-extraction project, give one case where you would use group-conditional conformal and one where you would use a normalized score or CQR. Group-conditional: you must report a guarantee per document source (each hospital, or each filing type such as 10-K vs 10-Q), and each source has a few hundred labeled documents. Normalized/CQR: difficulty varies continuously (document length, how many risks are mentioned, how ambiguous the language is), there is no small set of named groups, and you can train \(\hat\sigma\) or quantile models on document embeddings.
