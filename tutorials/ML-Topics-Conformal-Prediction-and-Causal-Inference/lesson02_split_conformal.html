Lesson 2: Split conformal prediction

About 60 minutes. Conformal prediction and causal inference series, lesson 2 of 16. Needs Lesson 1 (quantiles, exchangeability, the rank lemma).

Why this lesson Your risk-extraction model gives one answer per document: a severity score, or a risk type. It doesn't tell you how much to trust that answer. Split conformal prediction wraps any model, even an LLM you can only call through an API, and turns its single answer into a set of answers (a range of scores, or a few risk types) that contains the truth with a probability you choose, say 90%. The guarantee needs no assumptions about the model or the data distribution; it only needs exchangeability. This is the base that every later lesson builds on.

2.1 The goal in plain words

We have a model \(\hat f\) that takes an input \(x\) (a document) and outputs a guess. We want a prediction set \(C(x)\): a range of values, or a set of labels, such that for a new document

\[ P\big(Y_{\text{new}} \in C(X_{\text{new}})\big) \;\ge\; 1-\alpha . \]
  • \(\alpha\) is the error rate you are willing to accept. \(\alpha=0.1\) means "the set must contain the true answer at least 90% of the time".
  • \(Y_{\text{new}}\) is the true answer (for example, the doctor's rating), which we don't see at prediction time.
  • We want the set to be small when the model is confident and large when it isn't. A set that always contains everything is valid but useless.

Two examples we will use:

  • A (regression): predict a patient's severity score \(y\in[0,10]\) from their note. The set is an interval.
  • B (classification): label the main risk in a paragraph of a financial filing as one of {Credit, Liquidity, Market, Operational, Legal}. The set is a group of labels.

Split conformal prediction.
  1. Split the labeled data into a training part (used to build \(\hat f\)) and a calibration part \((X_1,Y_1),\dots,(X_n,Y_n)\) that the model has never seen.
  2. Choose a score \(s(x,y)\): a number saying how badly the answer \(y\) disagrees with the model at input \(x\). Large = bad. For regression the usual choice is \(s(x,y)=|y-\hat f(x)|\).
  3. Score the calibration set: \(s_i=s(X_i,Y_i)\) for \(i=1,\dots,n\).
  4. Take the threshold \[ k=\big\lceil (1-\alpha)(n+1)\big\rceil,\qquad \hat q = s_{(k)}\ \ (\text{the } k\text{-th smallest score}). \] If \(k>n\), set \(\hat q=+\infty\) (not enough data; the set is everything).
  5. Predict: for a new input \(x\), output every answer whose score is within the threshold, \[ C(x)=\{\,y : s(x,y)\le \hat q\,\}. \] With \(s=|y-\hat f(x)|\) this is simply the interval \([\hat f(x)-\hat q,\ \hat f(x)+\hat q]\).

Worked example (the running example from Lesson 1). The 10 calibration errors were 0.3, 1.2, 0.7, 2.5, 0.1, 0.9, 1.8, 0.4, 3.1, 1.0; sorted: 0.1, 0.3, 0.4, 0.7, 0.9, 1.0, 1.2, 1.8, 2.5, 3.1. A new note arrives and the model predicts \(\hat f(x)=6.2\).

2.3 The guarantee and its proof

Theorem (coverage of split conformal). Suppose the calibration points and the new point \((X_1,Y_1),\dots,(X_n,Y_n),(X_{n+1},Y_{n+1})\) are exchangeable, and the score function \(s\) was fixed without using them. Then \[ P\big(Y_{n+1}\in C(X_{n+1})\big)\;\ge\;1-\alpha . \] If in addition the scores have no ties, then also \[ P\big(Y_{n+1}\in C(X_{n+1})\big)\;\le\;1-\alpha+\frac{1}{n+1}. \]

Proof. We only need Lesson 1.

  1. The scores are exchangeable. \(s\) is a fixed function (the model was trained on other data), and fixed functions of exchangeable points are exchangeable (Lesson 1, §1.5). So \(s_1,\dots,s_n,s_{n+1}\) are exchangeable, where \(s_{n+1}=s(X_{n+1},Y_{n+1})\) is the score of the new point's true answer.
  2. Coverage is a rank event. By definition, \(Y_{n+1}\in C(X_{n+1})\) exactly when \(s_{n+1}\le\hat q=s_{(k)}\): the new score is at most the \(k\)-th smallest calibration score.
  3. Apply the rank lemma's corollary (Lesson 1, §1.6): \(P(s_{n+1}\le s_{(k)})\ge k/(n+1)\), with equality if there are no ties.
  4. Lower bound. \(k=\lceil(1-\alpha)(n+1)\rceil\ge(1-\alpha)(n+1)\), so \(k/(n+1)\ge 1-\alpha\).
  5. Upper bound. A ceiling adds less than 1: \(k<(1-\alpha)(n+1)+1\), so \(k/(n+1)<1-\alpha+1/(n+1)\). \(\square\)
What just happened The model, the score and the data distribution never entered the proof. The model only decides how large the sets are: a good model gives small scores, hence a small \(\hat q\) and tight sets; a bad model gives wide sets. The 90% is guaranteed either way. And the upper bound says the method doesn't waste coverage: with \(n=1000\) and \(\alpha=0.1\), coverage is between 90% and 90.1%.

Why "\(n+1\)"? The new point is the \((n+1)\)-th card in the deck. Its rank is uniform over \(n+1\) positions, not \(n\). Using the plain empirical quantile \(s_{(\lceil(1-\alpha)n\rceil)}\) would give slightly less than \(1-\alpha\) (in the worked example, 81.8% instead of 90%).

2.4 Why split the data?

Step 1 of the proof needs the score function to be fixed before we look at the calibration and test points. What if we skipped the split and computed scores on the training data?

Extreme example. Take a "model" that memorizes: for any training note it returns the doctor's exact rating (a 1-nearest-neighbor model does this). Every training error is 0, so \(\hat q=0\) and the interval is a single point. On a new note the error is not 0, so coverage is close to 0%, not 90%. Training errors are too optimistic because the model has already seen those answers.

Less extreme models overfit less, but the direction is always the same: errors on seen data are smaller than errors on new data, so the threshold is too small and coverage falls short. The split removes this problem by giving the model no chance to see the calibration answers.

Full conformal prediction (the original version of the method) avoids splitting by refitting the model with the new point included, once for every candidate answer \(y\). That keeps everything symmetric and uses all data, but costs one refit per candidate. Split conformal is the practical default, especially for LLMs, which you cannot refit at all. The cost of splitting is fewer points for training; in practice a few hundred to a few thousand calibration points are enough.

2.5 Interactive demo

Simulated data for example A. The input \(x\) is the length of the note in pages (0 to 10). Longer notes describe more complicated patients, so the true severity is noisier there. The model \(\hat f\) is a slightly-off straight line. We calibrate on \(n\) notes and test on 1,000 fresh notes.

Things to notice:

  • Overall test coverage lands close to \(1-\alpha\) for every \(\alpha\) and every \(n\). It can land a little below \(1-\alpha\) on one click (say 89%) and above on the next: the guarantee is an average over calibration sets. With \(n=20\) it wobbles much more (section 2.6 explains exactly how much).
  • The band has the same width everywhere, because the score \(|y-\hat f(x)|\) doesn't know which notes are harder. So short notes are covered almost always, while long notes are covered much less than 90%. The overall 90% is an average of the two. Lesson 3 fixes this with better scores.

2.6 What "90%" does and doesn't mean

The probability in the theorem is over two random things: which calibration set you happened to draw, and which new point arrives. This is called marginal coverage. Two common misreadings:

Misreading 1: "With my calibration set, exactly 90% of future points will be covered."

Once your calibration set is drawn, \(\hat q\) is fixed and the coverage for future points is the number \(c(\hat q)=P(s_{\text{new}}\le\hat q\mid\hat q)=F(\hat q)\), where \(F\) is the true CDF of the scores. This number is itself random, because \(\hat q\) depends on the calibration draw. How random?

By the PIT (Lesson 1, Fact B), \(F(s_1),\dots,F(s_n)\) are \(n\) uniform numbers, and \(F(\hat q)=F(s_{(k)})\) is the \(k\)-th smallest of them. A standard result says that the \(k\)-th smallest of \(n\) uniforms has a Beta distribution:

\[ c(\hat q)\ \sim\ \mathrm{Beta}\big(k,\ n+1-k\big),\qquad \mathbb E[c]=\frac{k}{n+1},\qquad \mathrm{sd}[c]=\sqrt{\frac{k\,(n+1-k)}{(n+1)^2\,(n+2)}} . \]

Again this doesn't depend on the score distribution. For \(\alpha=0.1\):

Misreading 2: "Each patient has a 90% chance of being covered."

The guarantee is an average over all patients. For particular kinds of patients (long notes, rare diseases, a specific hospital) coverage can be much lower or higher, as Figure 1 showed. Coverage that holds for every \(x\),

\[ P\big(Y\in C(X)\mid X=x\big)\ \ge\ 1-\alpha\quad\text{for all } x, \]

is called conditional coverage. It is much stronger, and it turns out to be impossible to guarantee exactly without assumptions, using finite data. Lesson 3 shows how to get closer (better scores, and coverage guaranteed within chosen groups).

2.7 Classification: sets of labels

Most classifiers (and LLMs, if you ask for label probabilities) output a probability \(\hat p_y(x)\) for each label \(y\). A natural score is

\[ s(x,y)=1-\hat p_y(x)\qquad(\text{small when the model gives the true label high probability}). \]

The set \(\{y: s(x,y)\le\hat q\}\) becomes

\[ C(x)=\{\,y : \hat p_y(x)\ \ge\ 1-\hat q\,\}:\quad\text{"every label the model gives at least } 1-\hat q \text{ probability"}. \]

Worked example (example B). We have \(n=19\) calibration paragraphs. For each, the score is 1 minus the probability the model gave to the correct risk type. Sorted:

0.02, 0.05, 0.08, 0.10, 0.12, 0.15, 0.18, 0.20, 0.22, 0.25, 0.30, 0.33, 0.38, 0.45, 0.52, 0.60, 0.68, 0.75, 0.91

With \(\alpha=0.1\): \(k=\lceil 0.9\cdot 20\rceil=18\), so \(\hat q=0.75\), and the set contains every label with probability \(\ge 0.25\). Three new paragraphs:

paragraphCreditLiquidityMarketOperationalLegalset (\(\hat p\ge 0.25\))
A0.700.200.050.030.02{Credit}
B0.380.330.170.070.05{Credit, Liquidity}
C0.240.220.200.180.16{ } (empty)
  • Set size is an uncertainty signal. A: the model is sure. B: it hesitates between two types. That is useful in practice: send paragraphs with set size ≠ 1 to a human reviewer.
  • Empty sets are allowed. C gets an empty set: not even the top label is plausible enough. The guarantee still holds on average (empty sets are counted as misses, and the threshold accounts for them). In practice, an empty set is a red flag: an unusual paragraph, also worth sending to a human.
  • One true label per paragraph. Here each paragraph has a single main risk. When a document can contain several risks at once (the usual case in risk extraction), "the set contains the truth" is replaced by "the set misses few of the true risks". That is conformal risk control, Lesson 4.

2.8 How much calibration data?

  • To get a finite set at all, we need \(k\le n\): \(\lceil(1-\alpha)(n+1)\rceil\le n\), which works out to \(n\ge 1/\alpha-1\). So \(\alpha=0.1\) needs \(n\ge 9\), \(\alpha=0.05\) needs \(n\ge 19\), \(\alpha=0.01\) needs \(n\ge 99\).
  • To make the coverage of your calibration set reliable (section 2.6), the spread is about \(\sqrt{\alpha(1-\alpha)/n}\). For \(\alpha=0.1\): \(n=100\) gives ±3%, \(n=1000\) gives ±1%.
  • Labels cost money. In medical and financial extraction, a label is an expert's time. A few hundred carefully labeled calibration documents already give a usable guarantee, and they can be reused for every model you try, as long as they never touch training.

2.9 Checklist: what breaks the guarantee

  • Calibration data used for training or tuning the model (including early stopping or prompt selection). The scores are no longer exchangeable with the new point's score.
  • Choosing \(\alpha\), the score or the calibration set after looking at test results, then reporting the best one. Each choice is valid alone; picking the best afterwards is not.
  • Calibration from a different population than deployment (another hospital, another year, another industry). Exchangeability fails; Lesson 8 shows how to reweight.
  • Reading it as per-patient coverage. It is an average (section 2.6).
  • Noisy labels. The guarantee is about the labels as recorded. If doctors disagree, "covered" means "covers this doctor's rating".

Summary

  • Split conformal: train on one part, score the calibration part with a fixed \(s(x,y)\), set \(\hat q\) to the \(\lceil(1-\alpha)(n+1)\rceil\)-th smallest score, and predict \(C(x)=\{y: s(x,y)\le\hat q\}\).
  • Guarantee: \(1-\alpha\le P(Y_{n+1}\in C(X_{n+1}))\le 1-\alpha+\frac1{n+1}\). The proof is the rank lemma; nothing about the model or distribution is needed, only exchangeability.
  • The model and score affect only the size of the sets. The split is essential: scores on training data are too small.
  • The guarantee is marginal. For a fixed calibration set, coverage is Beta\((k,n+1-k)\), with spread about \(\sqrt{\alpha(1-\alpha)/n}\). It is not conditional on \(x\): some groups can be badly under-covered.
  • Classification: \(C(x)=\{y:\hat p_y(x)\ge 1-\hat q\}\). Set size measures uncertainty; empty and large sets are natural triggers for human review.

Quiz

1. You have \(n=49\) calibration scores and want 90% coverage. Which order statistic is \(\hat q\)? What are the guaranteed lower and upper bounds on coverage (no ties)? \(k=\lceil 0.9\cdot 50\rceil=45\), so \(\hat q=s_{(45)}\). Coverage is exactly \(45/50=0.90\), so lower bound 0.90 and upper bound \(0.9+1/50=0.92\) (the exact value 0.90 is within both).
2. You have only \(n=4\) calibration points and \(\alpha=0.1\). What does split conformal output? \(k=\lceil 0.9\cdot 5\rceil=\lceil 4.5\rceil=5>4\), so \(\hat q=+\infty\) and the set is every possible answer. With 4 points, no data-based threshold can promise 90%: the best is the maximum, which gives \(4/5=80\%\).
3. A colleague computes the scores on the model's training data "to save labels". What goes wrong, and in which direction? Training errors are smaller than errors on new data (the model has seen those answers). So \(\hat q\) is too small, the sets too narrow, and coverage below \(1-\alpha\). In the extreme (a memorizing model) coverage goes to about 0.
4. You replace your model with one that outputs random numbers. Does split conformal still give 90% coverage? What changes? Yes, coverage is still at least 90%: the proof never used the model's quality. What changes is the size: the scores are large, so \(\hat q\) is large and the sets are very wide (close to useless).
5. Overall coverage on your test set is 90%, but for notes longer than 8 pages it is 74%. Does this contradict the theorem? No. The theorem promises 90% on average over all notes (marginal coverage). Long notes can be under-covered as long as other notes are over-covered. Fixing this needs better scores or group-wise calibration (Lesson 3).
6. Classification with \(\hat q=0.6\). A paragraph gets probabilities Credit 0.45, Liquidity 0.40, Market 0.10, Operational 0.03, Legal 0.02. What is the set? What if \(\hat q=0.5\)? \(\hat q=0.6\): include labels with \(\hat p\ge 0.4\): {Credit, Liquidity}. \(\hat q=0.5\): include \(\hat p\ge 0.5\): no label qualifies, so the set is empty.
7. With \(n=100\) and \(\alpha=0.1\), you evaluate on a huge test set and get 87% coverage. Is your implementation broken? Not necessarily. For a single calibration set, coverage is Beta(91, 10), with mean 0.90 and sd 0.03. 87% is one sd below the mean, which happens often. (If you got 70%, or got 87% again and again with fresh calibration sets, then something is wrong.)
8. Why does step 1 of the proof need the model to be trained on separate data? Answer in terms of exchangeability. The scores \(s_1,\dots,s_{n+1}\) are exchangeable only if the same fixed function is applied to each point. If the model were trained on the calibration points but not the new point, the function would treat them differently (it has seen their answers), so swapping a calibration point with the new point would change the joint distribution of the scores.
9. In the classification example, why is it acceptable that paragraph C got an empty set? The guarantee is marginal: empty sets count as misses, and the threshold \(\hat q\) was chosen so that misses of all kinds happen at most 10% of the time on average. Empty sets are rare when the model is reasonable, and they are informative: they flag unusual inputs.
